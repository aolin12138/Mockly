Thinking & Logic

A correct Two Sum solution should iterate once through nums while tracking previously seen values in a hash map from value -> index. For each value x at index i, compute complement = target - x; if complement is already in the map, return [map[complement], i]. This guarantees you don’t use the same element twice and runs in O(n) time, which matches the constraints.
