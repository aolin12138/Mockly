Code Assessment

Your final code matches the answer key’s brute_force approach (nested loops) and therefore has O(n^2) time. The canonical optimal solution you missed is the single-pass hash map (value -> index) technique: for each number x at index i, check whether target-x has been seen; if so return [seen[target-x], i]; otherwise store x. That achieves O(n) time and is the expected approach for n up to 1e5. Separately, your function raises ValueError when it doesn’t find a pair; the tests expected [] for empty input, so the behavior should be adjusted to return an empty list (or otherwise follow the specified interface).
