def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

Your solution uses the standard complement lookup pattern: iterate once through nums, compute complement = target - n, and if the complement was seen earlier, return the pair of indices. Checking before inserting ensures you never reuse the same element, and storing the latest index for each value supports duplicates correctly when the matching value appears later.
