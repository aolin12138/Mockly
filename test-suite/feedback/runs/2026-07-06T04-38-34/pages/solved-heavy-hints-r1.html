def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

You began with a nested-loops brute-force plan, then recognized it would be too slow for up to 1e5 elements. With hints, you moved to the standard invariant: as you scan left-to-right, maintain a hash map from previously seen value to its index. At each index i, compute complement = target - nums[i] and if it's already in the map, return the stored index and i; otherwise store nums[i]. This ensures you never reuse the same element and correctly handles duplicates.
