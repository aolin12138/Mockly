def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

The solution maintains a hash map from number to its index for elements already processed. For each number n at index i, it computes complement = target - n and checks if that complement has been seen; if so, it returns the stored index and i. Checking before inserting ensures the same element is not used twice, and the single pass guarantees O(n) expected time.
