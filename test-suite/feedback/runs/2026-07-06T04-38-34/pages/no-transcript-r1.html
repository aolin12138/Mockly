def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

The solution maintains a dictionary mapping previously seen numbers to their indices. For each number `n` at index `i`, it computes `target - n` and checks if that complement has already been seen; if so, it returns the stored index and `i`. Checking before inserting ensures you never pair an element with itself, and the single pass guarantees O(n) time.
