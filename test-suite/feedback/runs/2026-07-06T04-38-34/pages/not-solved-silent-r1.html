Code Assessment

Compared with the answer key’s optimal solution (single-pass hash map of seen values -> index, checking complement before inserting), your code is missing the core technique: complement lookup. The canonical approach guarantees finding the unique pair in O(n) time by checking whether target - nums[i] has been seen; your implementation does not compute complements and therefore returns [] for virtually all valid Two Sum instances.

Next Steps

1

Implement Two Sum using the single-pass hash map (complement lookup) pattern.

Why

It matches the problem definition and achieves the optimal O(n) time expected by the answer key for up to 1e5 elements.

How

Maintain dict seen = {value: index}. For each i,val: comp = target - val; if comp in seen: return [seen[comp], i]; else seen[val] = i.
