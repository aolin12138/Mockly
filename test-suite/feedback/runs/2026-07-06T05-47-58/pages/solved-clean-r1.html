def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

You correctly identified brute force as O(n^2) and chose the canonical optimization: maintain a hash map from value to index while iterating, and for each number check whether its complement has already been seen. Checking the complement before inserting the current number prevents using the same element twice and naturally supports duplicate values by storing earlier indices and matching when the second instance appears.
