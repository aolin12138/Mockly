def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

The solution maintains a hash map from numbers seen so far to their indices. For each number n at index i, it computes complement = target - n and checks whether that complement has already appeared; if so, it returns the stored index and i. Checking before inserting the current element ensures the same element isn’t used twice, and duplicates are handled correctly because the earlier occurrence is stored when needed.

Code Assessment

Your final code is effectively identical to the answer key’s optimal pattern: single pass with a hash map of seen values -> index, checking the complement before insertion. The only minor gap is returning [] even though the problem guarantees a solution—fine for LeetCode-style signatures, but in general systems code you’d often assert/raise.
