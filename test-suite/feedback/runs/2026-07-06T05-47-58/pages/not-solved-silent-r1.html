Thinking & Logic

The final logic collects indices where nums[i] equals target. Two Sum instead requires finding two distinct indices (i, j) such that nums[i] + nums[j] == target. This mismatch explains why tests expecting pairs like [0,1] or cases with negatives/duplicates all returned []. The canonical reasoning is: for each element x at index i, the needed partner is (target - x); if that needed value was seen earlier, you’ve found the answer.

Code Assessment

Implementing the hash-map complement pattern would address correctness and still meet the constraints (n up to 1e5) efficiently.
