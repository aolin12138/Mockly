def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

Your final approach uses a single pass through the array while storing previously seen values mapped to their indices. For each number n at index i, you compute complement = target - n and check if it has been seen; if so, you return the prior index and i. Checking before inserting guarantees you don’t reuse the same element, and it naturally handles duplicates by keeping an index for each seen value.

Code Assessment
