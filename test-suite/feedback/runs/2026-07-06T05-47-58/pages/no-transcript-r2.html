def solve(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Thinking & Logic

Your solution keeps a hash map from value to its index for values encountered so far. For each number n at index i, it computes complement = target - n and checks whether that complement was seen earlier; if so, it immediately returns the pair of indices. Checking before inserting ensures you never pair an element with itself, aligning with the problem’s constraints and the answer key’s known pitfalls.
